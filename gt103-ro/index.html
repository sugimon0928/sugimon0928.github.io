BTC Fortress GT103 rclone RO

BTC Fortress GT103 rclone RO is a personal Google Drive read-only utility used by its owner for private research and document inspection.

Purpose

The application uses rclone and Google OAuth to list, view, and download Google Drive files when requested by the owner.

Google Drive Access

The application requests read-only access to Google Drive files. It does not request permission to upload, modify, or delete files.

Its rclone configuration uses the owner's AI_Fortress folder as the operational root. The OAuth permission itself is not restricted to that folder.

Personal Use

This application is intended only for its owner. It is not offered as a public service. Automated synchronization is not enabled.
