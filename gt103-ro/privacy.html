Privacy Policy

Last updated: November 2, 2026

About this application

BTC Fortress GT103 rclone RO is a personal Google Drive read-only utility operated by its owner. It uses rclone and Google OAuth for private research and document inspection. It is not offered as a public service.

Google user data accessed

The application requests the Google Drive read-only scope (drive.readonly). This scope allows viewing and downloading files and metadata across the owner's Google Drive.

The rclone configuration uses the AI_Fortress folder as its operational root, but this does not limit the OAuth permission to that folder.

Use of data

Google Drive data is accessed only when requested by the owner, for listing folders, inspecting files, and downloading selected files for private research.

The application does not request permission to upload, modify, or delete Google Drive files. Automated synchronization is not enabled.

Data storage and retention

OAuth credentials and tokens are stored locally in the owner's private rclone configuration on the GT103 computer.

Files explicitly downloaded by the owner may be retained on the owner's private computer until the owner chooses to delete them. File content is not stored by this website.

Data sharing

The application does not sell Google user data or use it for advertising. It does not intentionally share downloaded file contents with third parties. Google processes authentication and Drive requests as part of providing its services.

Security

Access uses Google's OAuth authorization. Credentials and tokens must not be published or shared. The owner is responsible for protecting the local computer and its configuration files.

Revocation and deletion

The owner can revoke the application's access through Google Account security settings. The owner can also remove local credentials and downloaded files from the private computer.

Google API Services User Data Policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For privacy questions, contact the app owner using the support email shown on the Google OAuth consent screen.
